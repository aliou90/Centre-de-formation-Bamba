🗄️ STRUCTURE BASE DE DONNÉES
═══════════════════════════════════════════════════════════════════════════════

  Table certificates (NOUVELLE)
  ─────────────────────────────
  id                INT PRIMARY KEY AUTOINCREMENT
  user_id           INT FOREIGN KEY → users
  book_title        VARCHAR(255)
  certificate_id    VARCHAR(50) UNIQUE
  completion_date   DATETIME DEFAULT NOW
  progression       INT DEFAULT 100
  created_at        TIMESTAMP DEFAULT NOW
  
  Constraints:
  ├─ FOREIGN KEY (user_id) → users(id) ON DELETE CASCADE
  └─ UNIQUE KEY (user_id, book_title) → 1 certificat max par user/course

     Générer le certificat en PDF (TCPDF si disponible)
