🎓 Gestion des Certificats

Bamba Formation - Système de certificats pour cours complétés

📋 Aperçu du système

🚀 Fonctionnement automatique

Les certificats sont générés automatiquement lorsqu'un utilisateur atteint 98% de progression dans un cours.

🎯 Identifiants uniques

Chaque certificat a un ID unique au format: CERT-{timestamp}-{random}

📄 Formats supportés

Export en HTML (imprimable) et PDF avancé avec TCPDF si disponible.

🔐 Sécurité

Les certificats sont vérifiables et liés à chaque utilisateur et cours.

✨ Fonctionnalités principales

  • Génération automatique de certificat à 98%+
  • ID de certificat unique et intra-générateur
  • Téléchargement en format HTML (imprimable/convertible PDF)
  • Génération PDF avancée avec TCPDF (optionnel)
  • Vérification d'ID de certificat (validation)
  • Logo en haut du certificat
  • Informations: nom apprenant, cours (latin + arabe), date, ID certificat
  • Un seul certificat par utilisateur et par cours
  • Certificat permanent (ne baisse pas même si progression réduit)

🔌 Endpoints API PHP

1️⃣ Vérifier certificats disponibles

Endpoint:

GET /rqt_certificate_check.php

Description: Récupère tous les certificats disponibles pour l'utilisateur connecté.

Réponse:

2️⃣ Vérifier un ID de certificat

Endpoint:

POST /rqt_certificate_verify.php

Description: Valide et récupère les infos d'un certificat via son ID.

Input:

{ "certificate_id": "CERT-1715779200-A7K9M2" }

Tester:

3️⃣ Télécharger certificat (HTML)

Endpoint:

GET /rqt_certificate_download.php?certificate_id=CERT-xxx&mode=html

Description: Génère un certificat en HTML (prêt pour impression/PDF).

Formats: HTML imprimable, convertible en PDF via navigateur

4️⃣ Générer PDF avec TCPDF

Endpoint:

GET /rqt_certificate_generate_pdf.php?certificate_id=CERT-xxx

Description: Génère un PDF direct si TCPDF est installé, sinon redirige vers HTML.

Dépendance: TCPDF (optionnel)

💻 Intégration Frontend

Charger la librairie JavaScript

<script src="assets/js/certificate-manager.js"></script>

Utiliser le gestionnaire de certificats

Créer une instance:

const certManager = new CertificateManager();

Fonctions disponibles:

  • checkAvailableCertificates() - Obtenir les certificats disponibles
  • downloadCertificate(id, format) - Télécharger un certificat
  • generatePdf(id) - Générer un PDF (TCPDF)
  • verifyCertificateId(id) - Vérifier un ID de certificat
  • showVerificationModal() - Afficher le modal de vérification
  • initializeCertificates() - Initialiser automatiquement

🚀 Installation & Configuration

1. Migrer la base de données

Pour MySQL:

php assets/database/init_mysql_db.php

Pour SQLite:

php assets/database/init_db.php

2. Installer TCPDF (optionnel)

Avec Composer:

composer require tecnickcom/tcpdf

Ou manuellement:

Télécharger depuis https://tcpdf.org/
Décompresser dans assets/TCPDF/

3. Intégrer dans votre page

<script src="assets/js/certificate-manager.js"></script>

La librairie s'initialise automatiquement au chargement de la page.
