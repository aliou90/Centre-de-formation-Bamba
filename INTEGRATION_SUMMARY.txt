🔌 INTÉGRATION TECHNIQUE
═════════════════════════════════════════════════════════════════════════════════

FLOW D'AFFICHAGE:

1. Page chargée
   └─ loadCertificatesIntegration()
      ├─ Charge certificate-manager.js ✓
      ├─ Charge certificates-integration.js ✓
      └─ Charge certificates-styles.css ✓

2. DOMContentLoaded
   └─ initEventListeners()
      ├─ Trouve #view-badges-btn
      ├─ Ajoute click listener
      └─ Lance updateCertificateButtons()

3. updateCertificateButtons() (tous les 30 sec)
   └─ Appelle certManager.checkAvailableCertificates()
      ├─ Récupère certificats de l'API
      ├─ Crée map: bookTitle → certificateId
      └─ Affiche les boutons pour les livres avec certificat

4. Clic sur 📥 Télécharger
   └─ Appelle certManager.downloadCertificate(certId, 'html')
      ├─ Ouvre /rqt_certificate_download.php?certificate_id=X
      └─ Affiche le certificat en A4 portrait dans nouvel onglet

5. Clic sur 🏆 Mes Certificats
   └─ Bootstrap ouvre le modal #certificates-modal
      └─ loadCertificatesModal()
         ├─ Charge les certificats
         ├─ Crée les cartes HTML
         └─ Affiche avec animations

🐛 DÉPANNAGE RAPIDE
═════════════════════════════════════════════════════════════════════════════════

❌ Boutons ne s'affichent pas?
   → F12 > Console: vérifier pas d'erreur
   → Vérifier certManager.checkAvailableCertificates() retourne données
   → Vérifier que rqt_certificate_check.php est accessible

❌ Modal ne s'ouvre pas?
   → F12 > Vérifier élément #certificates-modal existe
   → Vérifier bootstrap.js est chargé
   → Cliquer sur bouton avec F12 ouvert (voir erreurs)

❌ Certificats ne se téléchargent pas?
   → Vérifier user est authentifié ($_SESSION['user']['id'])
   → Vérifier certificate_id valide en BD
   → Vérifier que le certificat appartient à l'utilisateur
